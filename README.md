# edxr-app-banner

Platform-aware "get the app" steering for EducationXR web properties — the
Duolingo split: Apple's native Smart App Banner at the top (iOS Safari), a
self-contained custom bottom bar everywhere else (Android, iOS-in-Chrome,
macOS, Windows).

Consumed as a git-pinned dependency by `edxr-marketing` and `edxr-react-admin`:

```json
"edxr-app-banner": "github:heizenrader/edxr-app-banner#<commit-sha>"
```

Update here once; consumers bump their pin deliberately.

Design spec: `edxr-workspace/rapid-api/docs/superpowers/specs/2026-08-05-app-banner-wave1-design.md`
